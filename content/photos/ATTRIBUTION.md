# Photo credits

The portraits in `dist/ghosts/` are rendered from these photographs. Each is used
under a free licence that permits derivative works, and each requires attribution,
which is what this file is. The rendered ANSI art is a derivative work and carries
the same licence as its source.

Licences were checked for two things beyond "free": **NoDerivatives** photos are
excluded, because rendering one to ANSI is a derivative, and **NonCommercial**
photos are excluded, because this repository is public.
